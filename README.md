## Flappy Clone

Un clone de Flappy Bird en HTML/Canvas, sans dépendance.

Pour jouer, ouvre `index.html` dans un navigateur.

- **Voler** : clic, toucher de l'écran, `Espace` ou `↑`
- **Rejouer** : même commande après un Game Over
- Le record est conservé dans le navigateur (`localStorage`)
